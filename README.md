Собрано под твой сетап: **Minecraft Java 1.21.11 + Fabric**, **NVIDIA RTX 40/50 (AV1 NVENC)**,
**YouTube 1440p–4K**, монтаж **Premiere Pro + After Effects**.

и при этом не потерять PvP-отзывчивость (уровень LT1+ по MCTiers/PvPTiers).

## TL;DR — ответы на твои вопросы

| Вопрос | Ответ |
|---|---|
| **Почему было пиксельно при «рендере в 2К»** | 2К — это только разрешение. Каша = нет сглаживания (края-лесенки) + битрейт ниже ~0.15 бит/пиксель + апскейл вместо рендера + 4:2:0. YouTube берёт 1440p60 всего ~24 Мбит/с, а 2160p60 — 53–68 Мбит/с. Т.е. «2К» получает **меньше** бит на пиксель, чем 4К. |
| **Почему 30 fps «не плавно»** | 30 fps на быстрых панорамах — это физически дёргано; плюс если запись 60 → секвенция 30 с ресемплингом, получаются «двойные» кадры. Нужно: игра ≥120 fps стабильно → запись 60 → секвенция 60 → экспорт 60. |
| **Сборка** | Fabric 1.21.11 + Sodium-стек (см. `docs/02-sborka.md`). Готовый проверенный набор модов + PvP-моды уровня Ranked Optimized. |
| **Сглаживание без шейдеров** | Два рабочих пути: (A) **DSR/DLDSR 2.25x + Sodium** — суперсэмплинг на уровне драйвера, работает со всем; (B) **VulkanMod + Salt's Anti-Aliasing** — настоящие MSAA/SSAA/TAA/DLAA. Сравнение и настройки: `docs/03-antialiasing.md`. |
| **Чем записывать** | **OBS Studio + NVENC AV1, CQP 16–18, MKV, 60/120 fps**. Плюс **Flashback/Frameback** для повторного рендера клипов в 4K. Полный конфиг: `docs/05-obs.md`. |
| **Как рендерить в Premiere/AE** | Premiere — монтаж и экспорт (H.264 High 60–80 Мбит/с или HEVC Main10, «Maximum Render Quality» + «Maximum Depth»). AE — только графика/оверлеи. Детали: `docs/06-premiere-ae.md`. |
| **Чем улучшать после рендера** | **Topaz Video AI** (Proteus/Rhea XL, 2x → 4K), **Neat Video** (если полезли артефакты сжатия), **Shutter Encoder** (бесплатный перегон), **Flowframes** (интерполяция, только для slow-mo). Готовые пресеты: `docs/07-post-upscale.md`. |

## Главная мысль (сэкономит тебе недели)

Качество — это **цепочка**, и она равна самому слабому звену:

```
рендер игры (AA + разрешение)  →  захват (OBS, битрейт)  →  монтаж (без ресемплинга)
        →  экспорт (битрейт, 10 бит)  →  загрузка YouTube (его перекодировка)
```

Если на любом шаге потерял — апскейл в Topaz обратно детали **не вернёт**, он дорисует синтетику.
Поэтому порядок действий: сначала **AA в игре + честный битрейт при записи**, апскейл — только в конце как вишенка.

Твоя конкретная ошибка почти наверняка была в звене «захват»: низкий битрейт / маленький CQP-эквивалент +
отсутствие сглаживания, а «2К» в экспорте просто растянуло мыло.

## Быстрый старт: что сделать сегодня

1. **Проверь, что у тебя реально творится** — прогони `scripts/qc-check.sh` на старом видео.
   Увидишь битрейт, VFR, colour range. 90% «пикселей» видны уже там.
2. **Поставь сборку** по `docs/02-sborka.md` (30–40 минут, всё по ссылкам с точными версиями).
3. **Включи сглаживание** по `docs/03-antialiasing.md` — начни с пути A (DSR/DLDSR), он не ломает PvP-моды.
4. **Настрой OBS** по `configs/obs/README.md` (импорт профиля + проверка).
5. **Запиши 30-секундный тест** и сравни с прошлым видео. Дальше — только полировка.

> Для скриптов из `scripts/` нужен **FFmpeg** (в PATH): `ffmpeg -version` должен работать.
> Если его нет — поставь FFmpeg (Windows-сборка gyan.dev) и добавь `bin` в PATH.

## Дисклеймеры (честно)

- Версии модов актуальны на **ноябрь 2026** (Minecraft 1.21.11). Моды обновляются — если версии не совпали,
  бери последнюю под свою точную версию игры, ссылки в таблицах ведут на проект Modrinth.
- «Убрать пиксели полностью» нельзя: Minecraft — пиксель-арт по своей природе. Убирается **лесенка на краях**
  (aliasing) и **каша от сжатия**. Сами текстуры 16×16 останутся — это стиль игры, а не баг.
- Ничего из гайда не является читом: все моды клиентские и разрешены на PvP-серверах, если не сказано иное.
  Моды с ESP/SilentAim/Triggerbot и прочие «клиенты» из этой категории — бан, их тут нет.
