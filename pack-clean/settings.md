# Настройки после установки: чистый экран + идеальная картинка + минимум задержек

Установщик уже подложил `options.txt` (частицы минимальные, VSync off, 240 fps, FOV-эффекты off).
Остальное — 3 минуты руками. Ниже точные значения.

---

## 1. Mod Menu: 4 мода (это главное)

### BactroMod

| Параметр | Значение | Что делает |
|---|---|---|
| Brightness Boost | **15** | видно в тенях, без «белого экрана» |
| Pumpkin Blur | **OFF** | тыква не закрывает обзор |
| Fire Offset | **−100** | огонь не занимает пол-экрана |
| Shield Offset | **−30** | щит почти не мешает обзору |
| Fog | **OFF** | туман не скрывает противника |

### BetterHurtCam

| Параметр | Значение |
|---|---|
| Hurtcam Enabled | **OFF** |
| (если хочешь «старый» hurtcam) | Enabled ON + Type: Old + Multiplier 0.70 |

### Custom Shield Scale

| Параметр | Значение |
|---|---|
| Scale | **0.5** |
| Height | **−10** |
| Left/Right offset | 0 (по вкусу) |

### HitColor X

| Параметр | Значение |
|---|---|
| Цвет вспышки | белый или красный (контраст с кровью/бронёй) |
| Только по броне | ON, если хочешь различать попадания |

## 2. Options → Accessibility (убирает «болтанку» камеры)

| Параметр | Значение | Почему |
|---|---|---|
| Camera Bobbing | **0%** | камера не качается — целиться проще, кадры чище |
| Hand Bobbing | **30–40%** | рука не «летает», но есть ощущение движения |
| Hand Sway | 70% | по вкусу |
| FOV Effects | **0%** | спринт/зелья не растягивают картинку |
| Screen Distortion | **0–50%** | меньше искажений от урона/портала |

В `options.txt` это уже стоит как `fovEffectScale:0.0` и `screenEffectScale:0.0`.

---

## 3. Чистый экран: что ещё убрать

| Что | Как | Результат |
|---|---|---|
| Весь HUD (хотбар, сердца, чат) | **`F1`** в игре | пустой кадр, hitcolor-вспышка остаётся (это эффект, а не HUD) |
| Частицы | Options → Particles: **Minimal** (уже стоит `particles:2`) | нет листвы-«салюта», кодеру легче |
| Тучи | Video → Clouds: **Fancy** (для записи) / **OFF** (для PvP) | «Fast» = плоские фанерки |
| Туман | BactroMod → Fog OFF | видно дальше |
| Тряска | BetterHurtCam OFF + Camera Bobbing 0% | стабильный прицел |
| GUI Scale | **3** на 1440p, 3–4 на 4K | интерфейс не гигантский |

## 4. Идеальная картинка без шейдеров

### 4.1. Драйвер NVIDIA (главное!)

| Параметр | Значение |
|---|---|
| DSR / DLDSR | **2.25x** (на 1440p = рендер 3840×2160) |
| DSR Smoothness | **15%** |
| Antialiasing — Mode | Application-controlled |
| FXAA | **Off** |
| Anisotropic filtering | 16x (или через Sodium Extra) |
| Power management | Prefer maximum performance |
| Vertical sync | **Off** |
| Max frame rate | **240** (или 300) |

Проверка: `F3` в игре должен показывать `3840x2160` (или 3413×1920 при 1.78x).
Если показывает 2560×1440 — DSR не применился, перезапусти игру.

### 4.2. Sodium Extra → Quality

| Параметр | Значение |
|---|---|
| Mipmap Levels | **4x** (максимум) |
| Anisotropic Filtering | **16x** |
| Biome Blend | **5x5** |
| Clouds | Fancy |
| Weather | Fancy (для записи) |
| Leaves | Fancy |
| Fog | Off (PvP) / On (кино) |

### 4.3. Чего не делать

- Не ставь шейдеры (Iris) — ты просил без них, и для PvP они вредны.
- Не включай FXAA: мылит HUD и текст.
- Не включай «Fabulous»: лишние пост-эффекты + ломает Game Capture.
- Не «шарпи» картинку ни в игре, ни в экспорте: Minecraft и так резкий, шарп даёт ореолы.
- Не ставь Mipmap 0 и AF off: именно из-за них «мыло» и мерцание на дальних текстурах.

## 5. Задержки: системный уровень

| Настройка | Значение |
|---|---|
| Монитор | максимальная герцовка в Windows (144/165/240) |
| Мышь | 1000 Гц опроса, без acceleration |
| Windows → «Повышенная точность указателя» | **OFF** |
| Windows → скорость курсора | **6/11** (центр) |
| NVIDIA → Low Latency Mode | **On** (для PvP можно Ultra, но следи за записью) |
| NVIDIA → Power management | Prefer maximum performance |
| VSync в игре | **OFF** |
| Max Framerate | 240 (не Unlimited) |
| Windows → Game Mode | ON |
| Windows → Game Bar / DVR | **OFF** |
| Интернет | Ethernet, пинг < 40 мс, 0% потерь |

## 6. Сенса (быстро и без магии)

```
eDPI = DPI мыши × сенса в игре
```

| Стиль | eDPI |
|---|---|
| Sword, трекинг | 600–900 |
| Универсал | 900–1400 |
| Crystal / mace | 1400–2200 |

Выбрал — не меняй 2 недели. Mod Menu → Advanced Mouse Sensitivity: раздельная X/Y нужна только
если реально понимаешь зачем (для mace иногда X ниже).

- [ ] Получил урон — камера **не** дёрнулась
- [ ] Щит в руке **маленький**
- [ ] При ударе — **вспышка** нужного цвета
- [ ] Частиц почти нет
- [ ] `F3` показывает 4К (DSR) и стабильные 120+ fps
- [ ] Разворот на 180° — без рывков и «резинки»
- [ ] `F1` — экран чистый, только мир
