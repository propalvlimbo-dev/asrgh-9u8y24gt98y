# Состав сборки «PvP Clean 1.21.11» — каждый мод и зачем

Принцип: **на экране ничего лишнего**, всё остальное работает «под капотом» — fps, задержка, чистая картинка.
20 модов. Никаких HUD-панелей, миникарт, таймеров, счётчиков брони и прочего визуального мусора.

Установщик качает актуальные версии с Modrinth под `1.21.11 + Fabric`, поэтому таблица не устареет.

---

## 1. Оптимизация (fps и ровный frame time)

| Мод | Modrinth | Что даёт |
|---|---|---|
| **Sodium** | `sodium` | новый рендер-движок: +100–300% fps, меньше микро-статтеров, честные настройки качества |
| **Lithium** | `lithium` | оптимизация игровой логики: тики, ИИ, физика |
| **FerriteCore** | `ferrite-core` | −30–50% потребления памяти → меньше GC-пауз (а паузы = дёрганая запись) |
| **ModernFix** | `modernfix` | фиксы утечек, быстрый старт, меньше «залипаний» |
| **ImmediatelyFast** | `immediatelyfast` | быстрый рендер HUD/текста/сущностей |
| **Entity Culling** | `entityculling` | не рендерит то, что за спиной/за стенами |
| **ScalableLux** | `scalablelux` | быстрое освещение, меньше статтеров при прогрузке чанков |

## 2. Задержка (то самое «чтобы задержки убрались»)

| Мод | Modrinth | Что даёт |
|---|---|---|
| **Ixeris** | `ixeris` | выносит ввод и GLFW из рендер-потока → меньше input lag, ровнее кадры |
| **Tick Sync** | `tick-sync` | синхронизирует тики клиента с пакетами сервера: игроки двигаются на экране раньше |
| **Krypton** | `krypton` | оптимизация сетевого стека: меньше лага пакетов и «резинки» |

> Важно: моды убирают **локальную** задержку. Если у тебя 80 мс до сервера — сначала Ethernet/сервер поближе,
> и только потом моды. См. `../docs/04-pvp-lt1.md`, §1.

## 3. Чистый экран и PvP-визуал (ровно то, что ты просил)

| Мод | Modrinth | Что даёт |
|---|---|---|
| **HitColor X** | `hitcolorx` | цвет вспышки урона (в т.ч. по броне). **Единственное, что добавляет сборка на экран** |
| **BetterHurtCam** | `betterhurtcam` | полностью убирает тряску камеры при уроне (или старый hurtcam) |
| **BactroMod** | `bactromod` | Shield Offset (маленький щит), Fire Offset (огонь не закрывает экран), Brightness Boost, Pumpkin Blur OFF, Fog OFF |
| **Custom Shield Scale** | `shieldscale` | точный масштаб щита: 0.5 + height −10 = маленький щит, не мешающий обзору |
| **Mod Menu** | `modmenu` | меню настроек для всего вышеперечисленного |

## 4. Картинка (без шейдеров)

| Мод | Modrinth | Что даёт |
|---|---|---|
| **Sodium Extra** | `sodium-extra` | доступ к мипмапам (4x), anisotropic filtering (16x), облакам, погоде, туману, частицам |
| **Reese's Sodium Options** | `reeses-sodium-options` | нормальное меню настроек Sodium с вкладками |
| **Fullscreen Tweaks** | `fullscreen-tweaks` | корректный borderless-fullscreen (нужно для OBS Game Capture) |

Сглаживание — **не модом**, а драйвером: DSR/DLDSR `2.25x`. Так AA не конфликтует ни с одним модом сборки
и не мешает PvP. Подробно: `../docs/03-antialiasing.md`.

## 5. Удобство

| Мод | Modrinth | Что даёт |
|---|---|---|
| **Zoomify** | `zoomify` | зум — проверять края/сглаживание и разглядывать детали |
| **Fabric API** | `fabric-api` | база для всех модов |

Опционально (`-WithFlashback`):

| Мод | Modrinth | Что даёт |
|---|---|---|
| **Flashback** | `flashback` | запись реплеев и рендер клипов в 4K/120 с любого ракурса — лучший способ снимать красиво, играя на PvP-настройках |

## Что специально НЕ включено (и почему)

| Мод | Почему нет |
|---|---|
| Armor HUD / Partial Hearts / Effect Timer Plus | это лишние элементы на экране — ты просил минимум |
| Crosshair Addons / Combat Hitboxes | визуальный шум; при желании поставь отдельно |
| Tiers (ранг в нике) | не влияет на игру, добавляет текст на экран |
| Xaero's Minimap / World Map | миникарта в кадре и на экране — не для PvP |
| Disable Lighting / fullbright-моды | убивают атмосферу и тени на записи; яркости BactroMod хватает |
| Iris Shaders | ты просил без шейдеров; на PvP они только мешают |
| VulkanMod + Salt's Anti-Aliasing | мощный AA, но отдельный инстанс и риск конфликтов с PvP-модами. Нужен — см. `../docs/03-antialiasing.md`, путь B |
| OptiFine | в 1.21 несовместим с Sodium, fps хуже |
| C2ME / VMP | полезны для больших серверов и SMP, но могут конфликтовать с античитами и другими модами; в этой сборке не нужны |
| Любые ESP / SilentAim / AutoTotem / Reach | это читы: бан и потеря канала |

## Проверка после установки

1. Запусти игру. В списке модов (Mod Menu) должно быть ~20 позиций.
2. `F3` → fps: в обычной сцене на 1440p + DSR 2.25x ожидай 120–250 fps (RTX 4070+).
3. Открой Mod Menu → BactroMod → выстави Shield Offset −30 и Fire Offset −100.
4. BetterHurtCam → OFF. Проверь: получи урон — камера не дёргается.
5. Custom Shield Scale → 0.5. Проверь: щит в руке маленький.
6. HitColor X → выбери цвет. Ударь моба — вспышка нужного цвета.
7. Развернись на 180° — не должно быть «резинки» и провалов fps. Если есть — смотри `../docs/04-pvp-lt1.md`.
