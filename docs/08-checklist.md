# 08. Чек-листы

Три коротких списка. Распечатай/держи открытыми.

---

## A. Перед записью (2 минуты)

**Система**
- [ ] Монитор в максимальной герцовке, G-Sync/FreeSync не конфликтует с записью
- [ ] Питание: максимальная производительность
- [ ] Браузер/Discord/лишние вкладки закрыты (статтеры)
- [ ] На NVMe свободно ≥ 20% (иначе запись будет рваться)

**Игра**
- [ ] Профиль «ЗАПИСЬ» (или «PVP» + Flashback), VSync OFF, fps cap 240/300
- [ ] AA включён (DSR 2.25x / MSAA 4x / DLAA) — проверь зумом на заборе
- [ ] Mipmap 4x + AF 16x
- [ ] Fullscreen Tweaks / оконный режим (чтобы работал Game Capture)
- [ ] F3: fps стабилен, 1% low не проваливается

**OBS**
- [ ] Профиль с AV1, CQP 16–18, 60/120 fps, MKV
- [ ] Превью выключено
- [ ] Game Capture по окну, курсор OFF
- [ ] Индикатор «Пропущено кадров» = 0
- [ ] Тест 30–60 секунд → `scripts/qc-check.sh`

---

## B. Перед экспортом (Premiere)

- [ ] Секвенция = разрешение записи, 60.000 fps, Rec.709, Square Pixels, No Fields
- [ ] Ни один клип не масштабирован больше 100% (если нужно — апскейл отдельным шагом)
- [ ] Time Interpolation = Frame Sampling, Frame Blending OFF
- [ ] Нет случайных пропущенных кадров на стыках
- [ ] Звук: −14 LUFS, пики ≤ −1 dBTP, без клиппинга
- [ ] `Render at Maximum Depth` ON, `Use Maximum Render Quality` ON
- [ ] Битрейт: 4К60 → 70–90 Мбит/с, 1440p60 → 40–60 Мбит/с
- [ ] Профиль High / Main10, уровень 5.1–5.2
- [ ] Keyframe 2 сек
- [ ] Проверил 10 секунд экспорта в полном размере (не на превью!)

---

## C. Перед загрузкой на YouTube

- [ ] Файл 2160p60 (или 1440p60), CFR, без VFR
- [ ] `qc-check.sh` подтверждает битрейт/цвет/fps
- [ ] Название/описание/теги, миниатюра отдельным 4К-скриншотом (Fabrishot)
- [ ] Не «улучшал» видео через YouTube-редактор (он перекодирует ещё раз)
- [ ] Дождался обработки 2160p (иногда 10–30 минут), проверял **не 360p**

---

## D. Быстрая диагностика: «стало хуже — что смотреть»

| Что видишь | Куда смотреть |
|---|---|
| Лесенки | AA не работает (проверь, что DSR реально включился: `F3` в игре покажет разрешение) |
| Мыло | битрейт записи/экспорта |
| Квадраты | CQ слишком высокий (20+), либо H.264 при малом битрейте |
| Дёргается | fps cap, дропы, 30 fps в секвенции, Optical Flow |
| Мерцание листвы | Mipmap/AF/TAA |
| Полосы на небе | 8 бит вместо 10 |
| Серое/выцветшее | Full/Limited mismatch |
| «Пластик» | Topaz с денойзом/шарпом |
| Звон/ореолы | шарпеннинг (в игре/экспорте/Topaz) |
| Рассинхрон звука | VFR-источник или разные fps дорожек |

## E. «Золотые» числа, которые надо помнить

```
Запись:      AV1/HEVC, CQ 16–18, 60 fps, 1440p/4K, 10 бит, Limited, Rec.709
Битрейт:     запись ≥ 60 Мбит/с (1440p60), ≥ 120 Мбит/с (4K60)
Мастер:      ProRes 422 HQ / DNxHR HQX, 10 бит
YouTube:     2160p60 → 70–90 Мбит/с H.264 / 50–70 Мбит/с HEVC Main10
             1440p60 → 40–60 Мбит/с
Аудио:       AAC 320–384 кбит/с, 48 кГц, −14 LUFS, ≤ −1 dBTP
bpp-цель:    ≥ 0.20 для финала, ≥ 0.50 для записи
```
