# 05. Чем записывать: OBS, настройки, альтернативы и гигиена записи

Короткий ответ: **OBS Studio + NVENC AV1 (CQP 16–18) + MKV + 60 fps**, плюс **Flashback/Frameback**
для повторного рендера клипов в 4К. Всё остальное — либо хуже, либо для других задач.

---

## 1. Почему именно OBS

| Способ | Плюсы | Минусы | Вердикт |
|---|---|---|---|
| **OBS Studio** | любой кодек (AV1/HEVC/H.264), CQP, 10 бит, отдельные аудиодорожки, сцены, бесплатно | надо один раз настроить | **основной инструмент** |
| **Flashback / Frameback** | пишет саму игру (не экран), почти не ест fps, можно перерендерить клип в 4К/120 с motion blur | не для длинных сессий «на монтаж» | **для клипов и «кино»** |
| ShadowPlay / NVIDIA App | просто, аппаратно | нет CQP-тонкости, ограниченный битрейт, 4:2:0, неудобные дорожки | резерв |
| Medal / Outplayed | мгновенные клипы | качество ниже, привязка к сервису | только для Discord-клипов |
| Windows Game Bar | встроено | 1080p, низкий битрейт, дропы | **нет** |
| Запись внутри Premiere/AME | «всё в одном» | тормозит, дропы, не её работа | **нет** |
| OBS + Replay Buffer | всегда последние N минут | требует дисциплины | удобно для PvP-моментов |

---

## 2. Настройки OBS: шаг за шагом

Профиль для импорта: `configs/obs/` (см. `configs/obs/README.md`). Ниже — то же руками, с объяснениями.

### 2.1. Настройки → Видео

| Параметр | Значение | Комментарий |
|---|---|---|
| База (Canvas) | **3840×2160** (если рабочий стол в 4К через DSR) иначе **2560×1440** | база = что композитируешь |
| Выход (Scaled) | **то же, что база** | никакого рескейла в OBS! |
| Фильтр масштабирования | `Lanczos` (только если рескейл неизбежен) | Bicubic мылит |
| FPS | **60** (или **120**, если хочешь слоу-мо) | 30 — никогда |

> Правило: **OBS ничего не масштабирует**. Масштабирование — только в драйвере (DSR) или в посте.

### 2.2. Настройки → Вывод → режим «Расширенный»

**Вкладка «Запись»:**

| Параметр | Значение |
|---|---|
| Тип | `Стандартный` (Standard) |
| Путь | NVMe SSD, отдельный диск от игры |
| Формат | **MKV** (+ включи «Автоматически создавать mp4» / remux) |
| Кодер | **NVIDIA NVENC AV1** (RTX 40/50). Fallback: NVENC HEVC |
| Управление битрейтом | **CQP / CQ** |
| CQ Level | **16–18** (мастер), 18–20 (архив), 20–22 (черновики) |
| Пресет | **P7 (Slowest / Max Quality)** или P6 |
| Tuning | **High Quality** |
| Multipass | `Two Passes (Full Resolution)` |
| Profile | `main` (AV1) / `main10` (HEVC 10 бит) |
| Look-ahead | ON |
| Psycho Visual Tuning | ON |
| B-frames | 3–4 |
| Раздельное кодирование (Split Encode) | Auto |
| Повторные заголовки | OFF |

**Ориентиры по размеру файла (AV1 CQ18, 1440p60):** 60–120 Мбит/с, ~25–50 ГБ/час.
Это нормально: место дешевле, чем пересъёмка. Для 4К60 — 120–200 Мбит/с, 60–90 ГБ/час.

### 2.3. Расширенные настройки видео (цвет и аудио)

| Параметр | Значение | Почему |
|---|---|---|
| Цветовой формат | **P010** (10 бит) для AV1/HEVC, NV12 (8 бит) для H.264 | 10 бит убирает бандинг на небе/градиентах |
| Цветовое пространство | **Rec. 709** | SDR-стандарт |
| Диапазон | **Ограниченный (Limited/Partial)** | совпадает с YouTube; настрой так же в Premiere |
| Частота дискретизации | 48 кГц, стерео | стандарт видео |
| Дорожки | 1 — игра, 2 — микрофон, 3 — Discord (по желанию) | потом сводишь в Premiere |

> Если после экспорта картинка «выцветшая» или «чёрный стал серым» — это рассинхрон Full/Limited.
> Правило: **везде Limited** (OBS, Premiere, экспорт). Подробнее в `06`.

### 2.4. Настройки → Вывод → «Поток» (если стримишь параллельно)

Не смешивай: запись в CQP, стрим в CBR 6000–8000. Это две разные вкладки, оба работают одновременно.

### 2.5. Настройки → Расширенные

| Параметр | Значение |
|---|---|
| Приоритет процесса | `Выше обычного` (Above Normal) |
| Планировщик рендера | `Самый высокий` (или обычный, если есть дропы) |
| Запуск от имени администратора | ON (иначе game capture не видит окно) |
| «Ограничить захват» | OFF |

Плюс: **выключи превью** (правый клик по превью → «Отключить превью»). Экономит 5–15% GPU.

### 2.6. Источник: Game Capture, а не Display

1. Источник → `Захват игры` → режим `Захватить конкретное окно` → выбери окно Minecraft.
2. `Захватить курсор` — OFF (иначе мышь попадёт в кадр).
3. `Разрешить прозрачность` — OFF.
4. `Ограничение частоты захвата` — OFF.
5. Display Capture используй только для меню/рабочего стола.

Почему важно: при DSR рабочий стол может быть 4К, а окно игры — меньше; game capture берёт окно
с его реальным разрешением и без двойного ресемплинга.

### 2.7. Аудио

| Источник | Настройка |
|---|---|
| Микрофон | фильтр «Подавление шума» (RNNoise) + «Компрессор» + «Лимитер» + «Усиление» по вкусу |
| Игра | 100%, отдельная дорожка |
| Discord | отдельная дорожка (через Application Audio Capture) |
| Общий микс на YouTube | −14 LUFS integrated, true peak ≤ −1 dBTP |

Для качества звука: **320 кбит/с AAC, 48 кГц** — этого достаточно, чтобы после перекодировки YouTube
не появилось «металлического» призвука.

## 3. Проверка записи (обязательный шаг)

1. Запиши **тестовые 60 секунд** в реальной PvP-сцене (листва, толпа, быстрые повороты).
2. В OBS внизу: `Пропущено кадров` должно быть **0** (и по кодировщику, и по рендеру).
3. Прогони файл через скрипт:

```bash
bash scripts/qc-check.sh "запись.mkv"
```

4. Смотри на:
   - `fps` ровно 60.000 (CFR), не 59.7/60.2;
   - `bitrate` ≥ 60 Мбит/с на 1440p60 (иначе CQ слишком высокий или сцена простая);
   - `pix_fmt` `yuv420p10le` (если хотел 10 бит);
   - `color_range=tv` (Limited).
5. Открой файл и **поставь на паузу в полном размере**. Лесенки/каша видны сразу. Если каша — CQ ниже.

## 4. Альтернатива №1: Flashback (рендер клипов в 4К)

**Flashback** (Modrinth, Fabric, 1.21.11) — пишет не видео, а **саму сессию** (позиции, действия),
а потом рендерит её в видеофайл с любыми настройками графики, FPS, разрешением и ракурсом.

Зачем тебе:

- играешь на PvP-профиле с 300–400 fps;
- потом рендеришь момент с профилем «Запись»: 4K, 120 fps, AA/DLAA, киношная камера;
- получаешь идеальную плавность (кадры генерируются офлайн, а не захватываются);
- можно сделать слоу-мо без интерполяции — просто рендерь 120/240 fps и замедляй.

Порядок:

1. В игре `Flashback → Start Recording` (или Replay Buffer).
2. После сессии: `Replay → Edit/Render`.
3. Настройки рендера: разрешение 3840×2160, fps 60 или 120, битрейт/качество максимальные,
   профиль графики — «Запись» (Fancy + DSR/DLAA).
4. Дальше — обычный монтаж.

Ограничения: не для длинных сессий (файлы реплеев тяжёлые), требует практики с камерой.

## 5. Альтернатива №2: Frameback (мгновенные клипы + motion blur)

**Frameback** — мод 2026 года, объединяющий идеи Medal/Vestige/Flashback: держит последние N секунд игры,
пишет через NVENC, а потом умеет **перерендерить клип в лучшем качестве** (до 4K/120) с настоящим motion blur
из реальных кадров, и сразу сделать файл под Discord 10 МБ / Nitro 50 МБ.

Кому: если ты играешь и хочешь **клипы на лету** без потери fps. Для полноценных видео на YouTube —
всё равно OBS.

## 6. Гигиена записи: 10 правил, которые сохранят тебе качество

1. **Пиши на NVMe**, не на HDD и не на системный диск, если он забит > 80%.
2. **MKV всегда**, remux в MP4 после. Краш OBS с MP4 = битый файл.
3. **Не пиши в 30 fps** никогда. 60 — минимум.
4. **Ограничь fps в игре** (240/300). Unlimited = статтеры и перегрев.
5. **Не запускай второй OBS/стрим** одновременно с 4К-записью без теста.
6. **Не масштабируй в OBS** — только DSR/пост.
7. **Один CQ на проект**: не смешивай в одном видео клипы с CQ16 и CQ24 — будет видна разница.
8. **Проверяй дропы** каждые 10 минут записи (индикатор в OBS).
9. **Отдельные дорожки аудио** — иначе потом не отделишь микрофон от игры.
10. **Тестовая запись 60 секунд** перед каждой большой сессией — 1 минута, которая спасает 3 часа.

## 7. Что делать, если OBS «не видит» Minecraft

| Причина | Решение |
|---|---|
| Игра в эксклюзивном фуллскрине | `F11` → играть в окне; или мод **Fullscreen Tweaks** (borderless) |
| OBS не от админа, игра от админа (или наоборот) | запусти оба от админа |
| Источник — Display Capture, а игра на другом мониторе | используй Game Capture с выбором окна |
| VulkanMod | Game Capture может не работать → Display Capture или оконный режим |
| Ноутбук с Optimus | OBS должен работать на дискретной GPU (Параметры графики в Windows) |

## 8. Итоговый стек записи (то, что надо запомнить)

```
OBS Studio
  ├─ Canvas/Output: 2560×1440 или 3840×2160 (без рескейла)
  ├─ FPS: 60 (120 для слоу-мо)
  ├─ NVENC AV1, CQP/CQ 16–18, P7, High Quality, multipass fullres, look-ahead ON
  ├─ P010 10 бит, Rec.709, Limited, 48 кГц, 320 кбит/с
  ├─ MKV + remux, NVMe, OBS от админа, превью OFF
  └─ Game Capture по окну, курсор OFF

Flashback (для клипов) → рендер в 4К/120 с профилем «Запись»
Frameback (для мгновенных клипов) → 4К + motion blur
```
