# Настройка Sodium по экранам (разбор 1-в-1)

Цель: максимально чёткая картинка без шейдеров + запись. Порядок: General → Quality → Performance →
Sodium Extra (Рендеринг / Частицы / Детали) → драйвер (DSR).

## 1. Sodium → General

| Параметр | Дефолт | Ставим | Зачем |
|---|---|---|---|
| Прорисовка | 6 чанков | 10–12 | на 6 горизонт в тумане, чанки подгружаются в кадре |
| Симуляция | 6 | 8 | мобы не дёргаются на границе |
| Яркость | Авто | Яркий | «Авто» плавает от времени суток → плавает экспозиция |
| Интерфейс | 3x | 2 (1080p) / 3 (4K DSR) | HUD не должен занимать пол-экрана |
| Полноэкранный | выкл | вкл | стабильный frame time |
| Динамическое разрешение | выкл | **выкл** | включённое мылит картинку в движении |
| V-Sync | выкл | выкл | +задержка |
| Частота кадров | Максимум | Ограничить 165 | скачки frame time рвут запись |
| Индикатор сохранения | вкл | выкл | мигает в углу |

## 2. Sodium → Quality

| Параметр | Дефолт | Ставим | Зачем |
|---|---|---|---|
| Улучшенная прозрачность | выкл | вкл | корректная прозрачность стекла/воды, −2–5% fps |
| Облака | выкл | Fancy | для кино-кадров; PvP — выкл (0 fps) |
| Дальность облаков | 128 | 32 | за пределами прорисовки не нужны |
| Радиус эффектов погоды | 10 | 10–16 | 16 — если снимаешь дождь |
| Просветы в листьях | вкл | **вкл** | листва без дыр = «дорогая» картинка |
| Частицы | Минимум | Минимум, точечно — в Sodium Extra | «все off» делается в отдельной вкладке |
| **Мягкое освещение** | **выкл** | **ВКЛ** | главное для качества: градиенты вместо плоских плашек, −1–3% fps |
| Граница биомов | 5x5 | 7x7 | плавный переход биомов, −1–2% fps |
| До сущности | 100% | 100% | 50% экономит fps, но скины вдали «пропадают» |
| Тени сущностей | вкл | вкл | объекты «стоят» на земле |
| Биньетирование | выкл | **выкл** | затемняет углы, в видео лишнее |
| Проявление чанков | 0.75 s | **Выкл** | иначе подгрузка выглядит как «призраки» |
| **Уровни детализации** | 4x | **4x** | мипмапы = нет мерцания вдали (главный анти-шум), ✅ уже верно |
| **Фильтрация текстур** | Анизотропная | **Анизотропная** | чёткие текстуры под углом, ✅ уже верно |

Порядок «что даёт больше всего»: Мягкое освещение → мипмапы 4x → анизотропия → DSR → граница биомов.

## 3. Sodium → Performance

| Параметр | Сейчас | Ставим | Зачем |
|---|---|---|---|
| Chunk Update Threads | Default | Default | авто = по ядрам CPU |
| Chunk Updates | Deferred | **Deferred** | строит чанки за несколько кадров; `Immediately` = меньше лага при ломании блоков, но ниже fps |
| Use Block Face Culling | ✅ | ✅ | −30% невидимых граней |
| Use Fog Occlusion | ✅ | ✅ | не рисует то, что за туманом |
| Use Entity Culling | ✅ | ✅ | не рисует сущности за спиной |
| Animate Only Visible Textures | ✅ | ✅ | анимации вне экрана не считаются |
| Use No Error Context | ✅ | ✅ | меньше расходов на отладку |
| Block Transparency Limits | Safe | **Safe** | `Advanced` может дать артефакты прозрачности с ресурспаками |

## 4. Sodium → Advanced

| Параметр | Сейчас | Ставим | Зачем |
|---|---|---|---|
| Use Persistent Mapping | ✅ | ✅ | быстрее буферы, стабильнее frametime |
| CPU Render-Ahead Limit | 3 | **3** (4K-запись) / **2** (PvP-лаг) | меньше кадров в очереди = меньше задержка, но и меньше fps |

## 5. Sodium Extra → Анимация

Сейчас **всё выключено** (вода, лава, огонь, портал, анимации блоков стоят кадрами) — это самый дешёвый вид
из всех настроек. Включить **«Все»**, при желании оставить выключенным только «Скалковый сенсор».

Цена: 1–2% fps за все анимации вместе.

## 6. Sodium Extra → Частицы

Здесь и делается «ноль частиц»: каждая строка — отдельный тип (тотем, дым, взрыв, вихрь, взмах меча,
брызги, водоворот и т.д.). Для чистого экрана — всё выключено (как сейчас).
Отдельно: «Взмах меча» off убирает серый полумесяц, «Взрыв» off — главный сейв fps на кристалл-PvP.
Обратная связь по попаданию остаётся за HitColor X (это не частица).

## 7. Sodium Extra → Детали

Сейчас **всё выключено**: нет градиента неба, солнца, звёзд, луны и **цветов биомов** (трава становится
однотонно-зелёной). Включить: Небо, Звёзды, Солнце, Луна, Цвета биомов, Цвета неба.
Погода — по вкусу (дождь в видео обычно мешает).

Цена: ~0–1% fps, вид меняется радикально.

## 8. Sodium Extra → Рендеринг (туман)

| Параметр | Сейчас | Ставим | Зачем |
|---|---|---|---|
| Advanced Fog Settings | выкл | **вкл** | открывает ползунки дальности тумана |
| Fog Distance | По умолчанию | **200%** | туман не съедает дальние чанки — исчезает «молочный горизонт» |
| Прозрачность тумана | 100% | 100% | — |
| Fog Shape | Vanilla | Vanilla | — |
| Cloud Fog | 100% | **0%** | облака не заволакивают горизонт |

Для чистой записи:

| Параметр | Ставим | Зачем |
|---|---|---|
| Показывать FPS | по вкусу (для записи — выкл) | счётчик в углу |
| Расширенный счётчик FPS | выкл | лишний текст |
| Показывать координаты | выкл | — |
| Уведомления (тосты) | **выкл** | всплывашки портят кадр |
| Достижения | **выкл** | плашка достижения в кадре |
| Новые рецепты | **выкл** | тост рецепта |
| Системные уведомления | **выкл** | — |
| Обучающие подсказки | **выкл** | жёлтые подсказки поверх игры |

| Panini Projection | **выкл** | искажает геометрию, для записи не нужно |
| Steady Debug HUD | выкл | нужно только для отладки |

## Итог: что реально влияет

1. Мягкое освещение — вкл (было выкл).
2. Анимации — вкл (было выкл).
3. Детали (небо/солнце/цвета биомов) — вкл (было выкл).
4. Мипмапы 4x + анизотропия — уже ок.
5. Туман 200% / cloud fog 0% — убирает «молоко» на горизонте.
6. Дальше всех этих галочек вместе взятых даёт DSR/DLDSR в драйвере.
