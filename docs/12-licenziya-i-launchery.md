# 12. Лицензия, лаунчеры и «оптимизированный лаунчер» — как есть

## Коротко

1. **Лаунчер не влияет на FPS, сглаживание и качество картинки.** Он только запускает Java-процесс.
   За fps отвечают: моды (Sodium-стек), версия Java, настройки игры и драйвер. За картинку — DSR/DLDSR,
   мипмапы и AF. Смена лаунчера не даёт ни одного лишнего кадра.
2. **«Оптимизированный лаунчер» — маркетинг.** Есть клиенты с набором оптимизаций (Lunar Client, Badlion),
   но выигрыш идёт от их модов, а не от «лаунчера»; тот же Sodium даёт то же самое в Prism.
3. **Лицензия нужна везде.** Prism, Modrinth App, официальный лаунчер, Lunar Client, ATLauncher —
   все входят через аккаунт Microsoft. Обход лицензии — не тема этого гайда.
4. **PvP-серверы без лицензии не пускают.** Античиты и вход по Microsoft отсекают такие аккаунты,
   так что «поиграть на пиратке в PvP» технически не получится — только одиночка/локальная сеть.

## Легальные способы начать играть (от дешёвого к простому)

| Вариант | Цена | Что даёт |
|---|---|---|
| **PC Game Pass** | подписка (дешевле покупки), отменяется в любой момент | Minecraft Java + Bedrock, вход тем же Microsoft-аккаунтом |
| **Купить Minecraft: Java & Bedrock** | разово, навсегда | Java навсегда + Bedrock, оба у одного аккаунта |
| **Проверить, что уже куплено** | 0 | Зайди на `minecraft.net` → профиль. С 2022 Java и Bedrock продаются вместе: если Bedrock у тебя есть в Microsoft Store — Java, скорее всего, тоже есть |
| **Microsoft Family** | 0, если есть взрослый аккаунт | Ребёнку можно выдать доступ в рамках семьи (легально) |
| **Демо-режим** | 0 | Проверить сборку и картинку, но ограниченное время и без серверов |

Как активировать Game Pass, если решишь:
1. `xbox.com/game-pass` → **PC Game Pass** → оформить на тот же Microsoft-аккаунт, что в Prism.
2. В Prism: **Accounts → Add Microsoft Account** → войти.
3. Запустить инстанс — demo-режим пропадёт.

## «А есть клиент для PvP, который сам всё оптимизирует?»

Да, и он легальный — **Lunar Client** (и аналоги вроде Badlion):

- бесплатный, вход через Microsoft-аккаунт (лицензия нужна так же);
- внутри уже есть FPS-моды, hitcolor/hurtcam-настройки, зум, toggle-sprint;
- удобен, если не хочешь собирать моды руками;
- минус: сторонние Fabric-моды (наш набор) туда не поставить, а обновления под новые версии приходят позже.

Что выбрать:

| Ты хочешь | Бери |
|---|---|
| Свою сборку с точными настройками (наш вариант) | **Prism + PvP Clean** |
| «Поставил и играешь», минимум телодвижений | Lunar Client |
| Много модов, шейдеры, съёмка | Prism + Sodium/Iris |
| Максимальный контроль над качеством записи | Prism + наша сборка + OBS AV1 |

## Почему смена лаунчера не решит твою проблему с картинкой

Ты видел «полосы вдали и плохое качество» — это **не лаунчер**. Это:

1. **DSR/DLDSR не включён** → в Minecraft вообще нет сглаживания (в ванили его нет).
2. **Мипмапы/AF не выставлены** → дальние текстуры дают муар и рябь.
3. Разрешение игры не переключено на 4К после включения DSR.

Всё это настраивается в драйвере и в игре — от лаунчера не зависит. Пошагово: `11-sglazhivanie-bystro.md`.

## Что можно сделать прямо сейчас, без лицензии

- Проверить сборку в демо-режиме: моды, Mod Menu, настройки BactroMod/HitColor/Shield Scale.
- Настроить DSR/DLDSR и убедиться, что `F3` показывает 3840×2160 и края гладкие (это видно и в демо).
- Настроить OBS-профиль и пресеты экспорта в Premiere — они вообще не зависят от аккаунта.
- Когда лицензия появится — просто войти в аккаунт в Prism и играть, ничего переустанавливать не нужно.
