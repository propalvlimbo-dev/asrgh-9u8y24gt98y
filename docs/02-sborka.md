# 02. Сборка: Minecraft 1.21.11 + Fabric для максимального качества и PvP

Цель сборки — три вещи одновременно:

1. **Картинка**: сглаживание, стабильный frame time, никаких статтеров → чистый кадр на записи.
2. **Отзывчивость**: минимум input lag, 200–400 fps в PvP-сцене, чтобы играть на уровне LT1+ и выше.
3. **Совместимость**: всё клиентское, разрешено на PvP-серверах и не конфликтует с записью (OBS/Flashback).

Сборка = **Fabric + Sodium-стек + набор PvP-модов**. Никаких шейдеров: они не нужны для задачи «убрать пиксели»
(сглаживание делается отдельно, см. `03-antialiasing.md`).

---

## 0. Что нужно поставить до модов

| Компонент | Версия | Ссылка/примечание |
|---|---|---|
| Java | **Java 21** (для 1.21.11; 1.21.9+ требует 21) | Adoptium Temurin 21 x64 |
| Лаунчер | **Prism Launcher** или **Modrinth App** | Prism удобнее для нескольких инстансов: «Запись 4К», «PvP», «Vulkan» |
| Minecraft | **1.21.11** | последняя стабильная ветка 1.21 |
| Fabric Loader | 0.16.x+ | ставится лаунчером в 2 клика |
| RAM | 8–12 ГБ на инстанс (не больше!) | больше 12 ГБ часто **хуже** (паузы GC) |

**Почему Prism, а не официальный лаунчер:** тебе нужны минимум 2–3 инстанса с разными рендер-движками
(Sodium для игры, VulkanMod для «киношной» записи, чистый для тестов). Официальный лаунчер это делать больно.

### JVM-аргументы (Prism → Settings → Java → JVM arguments)

```
-Xms6G -Xmx10G -XX:+UseG1GC -XX:+ParallelRefProcEnabled -XX:MaxGCPauseMillis=200
-XX:+UnlockExperimentalVMOptions -XX:+DisableExplicitGC -XX:G1NewSizePercent=30
-XX:G1MaxNewSizePercent=40 -XX:G1HeapRegionSize=8M -XX:G1ReservePercent=20
-XX:InitiatingHeapOccupancyPercent=15 -XX:SurvivorRatio=32 -XX:MaxTenuringThreshold=1
```

Не ставь `-Xmx` больше 12 ГБ: GC-паузы начнут давать микро-статтеры, а именно они убивают плавность записи.

## 3. Порядок установки (по шагам)

1. Prism → **Add Instance** → Minecraft **1.21.11** → Fabric → создай.
2. Settings инстанса → Java → **Temurin 21**, `-Xmx10G`, вставь JVM-аргументы выше.
3. Скачай моды **строго под 1.21.11**. В Modrinth App / Prism это делается встроенным браузером модов —
   так ты не поймаешь «не та версия / не тот лоадер».
4. Запусти игру один раз, выйди. Проверь `logs/latest.log` на `ERROR`/`Mixin`.
5. Настрой по `04-pvp-lt1.md` и `03-antialiasing.md`.
6. Сделай **резервную копию инстанса** (Prism → Export instance). Дальше — эксперименты.

Если хочется просто готовое: поставь пак **Ranked Optimized** (`modrinth.com/modpack/ranked-optimized`)
на 1.21.11 — это эталонный PvP-набор с уже выкрученными настройками, а сверху добавь свои моды качества
(Sodium Extra / Reese's / Fullscreen Tweaks).

## 4. Настройки видео: два профиля

Тебе нужны **два** пресета, и переключать их надо осознанно.

### Профиль «ЗАПИСЬ» (максимум картинки)

| Параметр | Значение | Почему |
|---|---|---|
| Graphics | Fancy (не Fabulous) | Fabulous — пост-эффекты и лишняя нагрузка; на записи разницы почти нет |
| Render Distance | 12–16 | 16 даёт красивые планы, 12 — стабильный fps |
| Simulation Distance | 6–8 | на визуал почти не влияет, экономит CPU |
| Mipmap Levels | **4x** | убирает «муар» на дальних текстурах |
| Anisotropic Filtering | **16x** (Sodium Extra → Quality) | резкие текстуры под углом, без «мыла» |
| Biome Blend | 5x5 | плавные переходы биомов (на градиентах) |
| Clouds | Fancy | на «Fast» — плоские фанерки |
| Particles | All | на записи красиво; в PvP — Decreased (см. ниже) |
| Entity Shadows | ON | объём |
| Smooth Lighting | Maximum | нет грязных пятен света |
| Entity Distance | 100% | не «выключать» сущности — их будет видно на записи |
| VSync | **OFF** | VSync добавляет input lag и рвёт frame pacing |
| Max Framerate | **240** (или 180/300) | ровный frame time важнее максимума |
| GUI Scale | 3 (1440p) / 4 (4К) | на записи интерфейс должен быть читаемым, но не огромным |

### Профиль «PVP» (максимум отзывчивости)

| Параметр | Значение |
|---|---|
| Render Distance | 8–10 |
| Simulation Distance | 5 |
| Graphics | Fast/Fancy (по вкусу) |
| Particles | Decreased или Minimal |
| Clouds | OFF / Fast |
| Entity Shadows | OFF (в 1.21 с этим осторожно — визуальный фидбек) |
| Max Framerate | 240–360 (или «Unlimited» при мощном GPU) |
| Brightness | Bright (гамма 1.0) |
| View Bobbing | 0% (Camera) / 47% (Hand) |
| Hurtcam | OFF (BetterHurtCam) |

**Лайфхак уровня «про»:** играй на PVP-профиле с 400 fps, а красивые кадры получай **из реплея**.
Flashback пишет сессию, а потом рендерит её с профилем «ЗАПИСЬ» в 4К/120 и с любым сглаживанием.
Так у тебя одновременно и максимальная отзывчивость, и максимальная картинка. См. `05-obs.md`.

## 5. Частые проблемы сборки

| Симптом | Причина | Решение |
|---|---|---|
| Краш на старте | мод не под 1.21.11 / нет Fabric API | проверь версии, читай `latest.log` |
| Чёрный экран в полноэкранном | эксклюзивный фуллскрин + OBS | Fullscreen Tweaks (borderless), либо `F11` в окне |
| 30–60 fps на мощной карте | игра рендерит в 4К DSR без запаса / тяжёлый render distance | снизь RD, проверь, не включён ли Fabulous |
| Микро-статтеры каждые 10–20 сек | мало/много RAM, GC | `-Xmx10G`, G1-флаги, закрой браузер |
| Мыльные дальние текстуры | Mipmap 0, AF off | Mipmap 4x + AF 16x |
| «Мыло» на всём экране | включён DLSS/FSR из VulkanMod или апскейл монитора | проверь драйвер/настройки |
| В OBS картинка темнее/светлее | HDR/colour range | Rec.709 + Limited, см. `06` |
| Клавиши не работают в игре при записи | OBS «забирает» ввод | запускай OBS от админа, но **не** включай «Capture cursor» в game capture |

## 6. Если хочется «совсем без пикселей» — про текстуры

Сглаживание убирает лесенки, но сами текстуры остаются 16×16. Если цель — «чистая современная картинка»
без шейдеров, дальше два варианта:

1. **Ванильный стиль + AA** — самый безопасный путь для PvP-контента: зрители узнают игру, а картинка чистая.
2. **32x/64x пак в ванильном стиле** (Faithful 32x, Stay True, Bare Bones не подойдёт — он наоборот минималистичный).
   Важно: такие паки **не** улучшают восприятие в PvP (мелкие текстуры = лучше видно), поэтому на PvP-профиле
   оставь ванильные, а высокое разрешение используй только в «киношных» кадрах из Flashback.
