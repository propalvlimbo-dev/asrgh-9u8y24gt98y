# 04. PvP-сетап уровня LT1+ (1.21, легально) без потери качества картинки

Сразу про терминологию: **HT1 → LT1 → HT2 → LT2 …** — это тиры MCTiers/PvPTiers (High Tier / Low Tier).
LT1 — это уже верхний эшелон: люди с идеальным hit-select, стабильным aim и контролем дистанции.
Тир **не покупается настройками** — но настройки определяют твой потолок. Ниже — то, что реально влияет.

---

## 1. Железо и система: то, что нельзя исправить в игре

| Параметр | Как надо | Почему |
|---|---|---|
| Монитор | **144 Гц минимум, 240+ идеально** | 60 Гц физически ограничивает реакцию и трекинг |
| Режим монитора | максимальная герцовка в Windows, **Overdrive** средний | 60 Гц по умолчанию — самая частая потеря тира |
| Мышь | 1000 Гц опроса (8000 — по желанию), **без acceleration** | предсказуемость трекинга |
| Windows: «Повышенная точность указателя» | **ВЫКЛ** | это акселерация, ломает muscle memory |
| Windows: скорость курсора | **6/11 (по центру)** | 1:1 с физикой мыши |
| Windows: «Оптимизации для оконных игр» | ВКЛ | лучше frame pacing в borderless |
| Game Mode | ВКЛ, Game Bar/DVR — ВЫКЛ | DVR ест fps и пишет 30 fps |
| Питание | «Максимальная производительность» | микро-статтеры от троттлинга |
| Ethernet | кабель, не Wi-Fi | 5–15 мс и стабильность пакетов — это hit-reg |
| Интернет | < 40 мс до сервера, 0% потерь | лучше играть на сервере ближе к тебе |

## 2. Сенса и прицеливание: как считать, а не подбирать на глаз

### Сенса

Три величины связаны: **DPI × сенса в игре = эффективная сенса** (eDPI).

```
eDPI = DPI мыши × Minecraft sensitivity
```

Ориентиры для 1.21 PvP (sword/mace/crystal):

| Стиль | eDPI | Типичные значения |
|---|---|---|
| Низкая (трекинг, sword) | 600–900 | 800 DPI × 50–70% / 1600 DPI × 35–45% |
| Средняя (универсал) | 900–1400 | 1600 DPI × 55–75% |
| Высокая (crystal/mace, быстрые флики) | 1400–2200 | 1600 DPI × 85–110% / 3200 DPI × 45–60% |

Что делать: выбери **одну** eDPI и не меняй 2–3 недели. Организм адаптируется к сенсе за ~10–14 дней
ежедневной игры. Постоянные изменения = вечный «не могу попасть».

- **Turn-around тест:** от центра коврика до края поворот на 180° за одно движение рукой — удобно?
  Если нужно перехватывать мышь — сенса низкая. Если поворот делается «на 2 см» и ты проскакиваешь — высокая.
- **Трекинг-тест:** поставь бота/моба и води прицелом по его хитбоксу 30 секунд без рывков.
  Если прицел «дрожит» — сенса высоковата для твоего стиля.
- **Раздельная X/Y сенса** (мод Advanced Mouse Sensitivity): большинству не нужна, но для mace/кристаллов
  иногда X делают ниже Y. Меняй только если понимаешь зачем.

### DPI

- 800 или 1600 — оба нормальны. 1600 обычно даёт меньший «шаг» на низких сенсах.
- 3200+ бери только если мышь реально стабильна на этом DPI (не все сенсоры одинаковы).
- **Не** используй «сырой ввод» через сторонние утилиты — в 1.21 raw input уже родной.

### FOV

| Задача | FOV |
|---|---|
| Sword/ножи, аккуратный трекинг | 80–85 |
| Универсал | 85–90 |
| Crystal/mace, быстрые повороты | 90–100 |
| «Киношные» кадры | 70–80 (даже если играешь на 90 — рендер реплея можно сделать с другим FOV) |

Правило: **не меняй FOV перед турниром**. Он влияет на восприятие скорости и дистанции.
Если снимаешь контент — держи игровой FOV 85–90, а красивые планы делай в Flashback с FOV 70–75.

## 3. Настройки игры под PvP (и под запись)

### Обязательное

| Настройка | Значение | Зачем |
|---|---|---|
| **Toggle Sprint** | ON (или спринт на Shift-hold, как привык) | один палец свободен — это реально влияет |
| **View Bobbing (Camera)** | **0%** | болтанка камеры мешает целиться и портит кадры |
| **View Bobbing (Hand)** | 30–50% | рука не должна «летать» |
| **Hurtcam** | **OFF** (BetterHurtCam) | тряска при уроне — прямой минус к аиму |
| **Brightness (Gamma)** | **Bright / 1.0** | видеть в пещерах и тени |
| **Particles** | Decreased | меньше визуального шума, лучше видно хитбокс |
| **Fog** | OFF (BactroMod) | туман скрывает противника |
| **Fire overlay offset** | −100 (BactroMod) | огонь не закрывает пол-экрана |
| **Shield offset** | −30 | щит не закрывает обзор |
| **Pumpkin blur** | OFF | очевидно |
| **Crosshair** | маленький, контрастный, **не анимированный** | видеть точку хитбокса |
| **Hitboxes** | Combat Hitboxes: цвет цели меняется | визуальный фидбек дистанции |
| **Armor HUD** | ON | видеть прочность до того, как она кончится |
| **Effect Timer** | ON | тотемы/зелья — тайминги |
| **Autojump** | OFF | ломает стрейф-контроль |

### Что НЕ включать

| Не включай | Почему |
|---|---|
| Fabulous graphics | лишние пост-эффекты, ломает game capture |
| Motion blur / любые «киношные» эффекты | мылят картинку и мешают |
| Шейдеры в PvP | падение fps и потеря контраста силуэтов |
| Ресурспаки 128x+ | «шум» вместо читаемости (в PvP) |
| Динамическое освещение | скачки fps |
| Максимальный Render Distance в PvP | не влияет на бой, но режет fps |
| Читы/«клиенты» | бан + канал в мусорку |

## 4. Механики 1.21, которые надо знать (свежий патч)

С 1.21 боевка заметно отличается от 1.8 и от 1.16:

| Механика | Суть | Как тренировать |
|---|---|---|
| **Attack cooldown** | урон максимален только при полной зарядке (меч ~0.625 с) | ритм: удар → полный замах → удар; не «спамь» |
| **Shield** | блокирует почти всё, кроме топора/булавы и взрывов | bait-подход, удар топором, обход сбоку |
| **Mace (булава)** | урон при падении, «breach» пробивает броню | прыжок + тайминг удара в нижней точке |
| **Wind charge** | сбивает прыжок/позицию | отменять чужой mace-комбо |
| **Crystal PvP** | кристаллы Энда + якоря | тайминги постановки/взрыва, Hug-дистанция |
| **Sprint-reset (W-tap)** | сброс спринта для knockback-контроля | W-tap: короткий отпуск W перед ударом |
| **Hit-select** | попадание точно в момент максимальной зарядки + дистанция 3.0 | практика на ботах/друзьях, счётчик комбо |
| **Strafe / circle** | удержание дистанции 2.8–3.0 | круговой стрейф вокруг цели |
| **Jump reset** | прыжок в момент урона снижает knockback | тайминг по звуку удара |

### Где тренироваться (без банов и без «доната»)

- Серверы-практики: PvP-арены с ботами и дуэлями (в т.ч. те, что в моде **PvPTraining** / **PVP Arena**).
- Своя арена в креативе: бот-манекен + таймер.
- Записывай свои дуэли в **Flashback** и разбирай: где потерял дистанцию, где ударил не в полную зарядку.
  Это самый быстрый способ поднять тир — ты видишь свои ошибки глазами.

## 5. Связка «PvP-настройки» + «качество записи» без конфликта

Главный конфликт: PvP хочет **минимум графики и максимум fps**, запись хочет **AA и красивые настройки**.
Решение — **два инстанса и реплей**:

```
Инстанс «PvP»        → 8 чанков, Fast, без AA, 300–400 fps  → в него играешь
Инстанс «Запись»     → 16 чанков, Fancy, DSR 2.25x/MSAA      → в него рендеришь реплей
                        └─ Flashback/Frameback: пишет сессию, потом рендерит её
                           в 4К/120 fps с профилем «Запись»
```

Так ты не жертвуешь ни отзывчивостью, ни картинкой. Подробнее — `05-obs.md`, раздел «Flashback / Frameback».

## 6. Мини-план на 2 недели до «LT1-стабильности»

| День | Что делать |
|---|---|
| 1 | Зафиксировать eDPI и FOV. Записать их на бумажку. Больше не менять |
| 2–3 | Только aim-трекинг: бот, круговой стрейф, 20 мин/день |
| 4–5 | Тайминги: удары строго в полную зарядку (счётчик комбо) |
| 6–7 | W-tap и sprint-reset: 15 мин на арене |
| 8–9 | Дистанция: держать 2.8–3.0, наказывать за промах |
| 10–11 | Дуэли + разбор реплеев (Flashback), по 3–5 боёв |
| 12–14 | Полные матчи, фокус на hit-select и контроле позиции |

Параллельно: не меняй сенсу, не меняй моды, не меняй fps cap. Стабильность — это скучно, но именно она
отделяет LT1 от HT2.

## 7. Чек-лист перед каждой сессией

- [ ] Монитор в максимальной герцовке (проверь в настройках экрана, не на глаз)
- [ ] Windows: акселерация выкл, 6/11, Game DVR выкл
- [ ] Игра: VSync off, cap 240/300, FOV/hurtcam/bobbing как в таблицах
- [ ] OBS запущен (если пишешь), превью выключено, дропов нет
- [ ] Flashback включён, если планируешь рендерить клипы
- [ ] Discord/браузер закрыты (они дают статтеры и жрут fps)
- [ ] Разминка 10 минут на арене — без разминки тир не показывается
