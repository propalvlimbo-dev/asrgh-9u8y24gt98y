# 07. Улучшение качества после рендера: чем и когда

Правда, которую надо принять: **пост не создаёт детали, которых не было**. Он убирает артефакты сжатия
и растягивает картинку умнее, чем Bicubic. Поэтому порядок такой:

1. Сначала исправь причину (AA в игре, битрейт записи, 60 fps) — `01`–`05`.
2. Потом, если всё равно нужно 4К, — апскейл.

---

## 1. Кто за что отвечает

| Инструмент | Что делает | Когда использовать | Цена |
|---|---|---|---|
| **Topaz Video AI** | AI-апскейл, восстановление деталей, деинтерлейс, интерполяция | 1440p→4K, «спасение» старых записей | платно (есть триал) |
| **Neat Video** (плагин) | лучший денойз/удаление артефактов сжатия | если на записи «грязь», блочность, шум | платно |
| **Shutter Encoder** | бесплатный GUI для FFmpeg: x264/x265/SVT-AV1/ProRes | финальный перегон, мастер, ремукс | бесплатно |
| **FFmpeg** (CLI) | всё то же, но скриптами и пакетно | автоматизация, точный контроль | бесплатно |
| **Flowframes / SVP** | интерполяция кадров (RIFE) | slow-mo, а не «60→120 для YouTube» | бесплатно/платно |
| **Lossless Scaling** | realtime-апскейл и frame gen для игры | только для игры/просмотра, **не** для записи мастера | платно (дешево) |
| **DaVinci Resolve** | монтаж + хороший энкодер | альтернатива Premiere | бесплатно |

## 2. Topaz Video AI: настройки под Minecraft

### 2.1. Что подавать на вход

- **ProRes 422 HQ / DNxHR мастер**, не YouTube-файл и не «скормил OBS-запись в MKV/AV1» (Topaz его
  может не открыть или декодировать с потерями).
- Разрешение входа: 1440p (если писал 1440p). Апскейл ×1.5–2 до 2160p.
- fps: без изменений (60 → 60).

### 2.2. Какой моделью

Minecraft — это **чистая CG-графика с резкими краями и большими плашками цвета**. Поэтому:

| Модель | Подходит? | Комментарий |
|---|---|---|
| **Proteus** | ★★★★★ | рабочая лошадка: сначала `Auto/Estimate`, потом ручная доводка |
| **Rhea / Rhea XL** | ★★★★ | максимум текстуры при 2×; может «дорисовать» лишнее на блоках — проверяй превью |
| **Gaia (HQ)** | ★★★★ | для CG/анимации: чистые линии, не мылит текстуры — хороший второй кандидат |
| **Iris (MQ/LQ)** | ★★ | для лиц; на пейзажах Minecraft бесполезен |
| **Nyx / Nyx XL** | ★★ | только если реально шумно/темно; иначе пере-сглаживает |
| **Artemis** | ★★ | устаревшая, но иногда спасает мягкие записи |
| **Starlight / Starlight Mini** | ★ | для убитого материала (240p, VHS). Для чистого 1440p — оверкилл и «пластик» |
| **Theia** | ★★★ | если нужен ручной контроль резкости/деталей |

### 2.3. Стартовые значения (Proteus, 1440p → 4K, чистый источник)

| Параметр | Значение |
|---|---|
| Mode | Manual (после `Auto/Estimate`) |
| Revert Compression | **15–25** (у тебя нет сильного сжатия — не переусердствуй) |
| Recover Detail | **30–45** |
| Sharpen | **0–8** (Minecraft не надо шарпить — появятся ореолы) |
| Reduce Noise | **0** |
| Dehalo | **0–5** |
| Anti-alias / Deblur | **0** (AA уже сделан в игре) |
| Add Noise | **0** (иначе кодеру станет хуже) |
| Output | HEVC Main10, 4К, bitrate 60–90 Мбит/с, или ProRes 422 HQ |

Для 2× с максимальной текстурой: **Rhea XL**, `Sharpen 0`, `Recover Detail 40`, потом сравни с Proteus
на одном и том же кадре (в Topaz есть `Compare`).

### 2.4. Чего не делать

- **Не апскейлить дважды** (1440→4K→8K). Второй проход только добавит синтетики.
- **Не включать денойз на чистом материале** — потеряешь микродетали текстур.
- **Не интерполировать 60→120** для YouTube: платформа всё равно отдаст 60, а артефакты останутся.
- **Не апскейлить уже сжатый YouTube-файл** — восстановишь артефакты сжатия, а не детали.
- **Не «шарпить» после апскейла** в Premiere — двойная резкость = звон.

### 2.5. Порядок в пайплайне

```
OBS-запись → Premiere (монтаж) → мастер ProRes 422 HQ
   → Topaz (Proteus 2×, 4К, HEVC Main10) → 4К-мастер
   → Premiere (4К-таймлайн: титры/графика, без масштабирования)
   → финальный экспорт H.264 70–90 Мбит/с или HEVC Main10
```

Если апскейл долгий (а он долгий: 4К60 на RTX 4070 — примерно ×3–×6 от реального времени),
делай его ночью/пакетно через `Process → Export All`.

## 3. Neat Video: когда запись «грязная»

Признаки: блочность на градиентах, «мушка» в тёмных сценах, шум от высокого ISO-эквивалента (не твой случай),
артефакты после жёсткого сжатия старых клипов.

Настройки для геймплея (внутри Premiere/AE):

| Параметр | Значение |
|---|---|
| Temporal frames | **2–3** (больше — «призраки» на движении) |
| Noise profile | построй по **плоскому участку** (небо/стена), не по листве |
| Radius | 1–2 |
| Denoise amount | 40–60% |
| Sharpen | 0–10 (Neat сам добавит резкости, осторожно) |

Правило: Neat — **до** апскейла, если он вообще нужен. Но лучше не доводить до него.

## 4. Shutter Encoder / FFmpeg: бесплатная «сантехника»

### Shutter Encoder (GUI)

- `Простой ремукс` MKV → MP4;
- `H.264` / `H.265` с CRF;
- `AV1 (SVT)` с preset 4–8 и CRF 20–24;
- `ProRes` / `DNxHR` для мастеров;
- `Analyse` — быстро посмотреть битрейт/fps/дропы.

### Скрипты в репозитории

```bash
# 1) проверить запись: fps, битрейт, bpp, VFR, цвет
bash scripts/qc-check.sh recording.mkv

# 2) собрать мастер из записи (x264 CRF 14, очень высокое качество, большой файл)
bash scripts/master-encode.sh recording.mkv master.mp4

# 3) апскейл 1440p → 4K (Lanczos + очень лёгкий unsharp)
bash scripts/upscale-4k.sh master.mp4 master-4k.mp4

# 4) прокси для Premiere
bash scripts/proxies.sh ./footage ./proxies
```

### Ключевые команды (если хочешь руками)

```bash
# H.264 мастер, визуально прозрачный
ffmpeg -i in.mkv -c:v libx264 -preset slow -crf 14 -pix_fmt yuv420p \
       -profile:v high -level 5.2 -x264-params keyint=120:min-keyint=60 \
       -colorspace bt709 -color_primaries bt709 -color_trc bt709 -color_range tv \
       -c:a aac -b:a 320k -ar 48000 out.mp4

# HEVC 10 бит, компактнее при том же качестве
ffmpeg -i in.mkv -c:v libx265 -preset slow -crf 17 -pix_fmt yuv420p10le \
       -x265-params "profile=main10:keyint=120:bframes=4" \
       -colorspace bt709 -color_primaries bt709 -color_trc bt709 -color_range tv \
       -c:a aac -b:a 384k out.mp4

# Апскейл 1440p → 4K с аккуратной резкостью
ffmpeg -i in.mp4 -vf "scale=3840:2160:flags=lanczos+accurate_rnd+full_chroma_int,unsharp=5:5:0.25:5:5:0.0" \
       -c:v libx265 -preset slow -crf 17 -pix_fmt yuv420p10le -c:a copy out-4k.mp4
```

> Замечание: `unsharp` — по вкусу, 0.2–0.3 максимум. Больше — «звон» на блоках.

## 5. Flowframes / RIFE: интерполяция (только для slow-mo)

- Нужна плавная замедленная вставка из 60 fps? Интерполируй **в 4× (240 fps)** и замедляй в Premiere.
- Модель: RIFE 4.x, `UHD` mode, output mp4/ProRes.
- Не применяй к быстрым поворотам камеры (артефакты «желе» на HUD и листве).
- Альтернатива без артефактов: рендер слоу-мо в Flashback с 240 fps сразу.
