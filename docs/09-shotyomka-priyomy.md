# 09. Приёмы съёмки: чтобы «технически чисто» стало «профессионально»

Техническое качество — фундамент, но видео смотрят из-за картинки и темпа. Ниже то, что отличает
ролик «я записал геймплей» от ролика, который выглядит дорого — без шейдеров и без спецэффектов.

---

## 1. Кадр: что делать с камерой

| Приём | Как делать | Зачем |
|---|---|---|
| **Плавные панорамы** | в Flashback/реплее — медленный поворот 5–8°/с | ручная мышь всегда даёт микро-рывки |
| **Push-in / pull-out** | реплей + движение камеры к объекту 1–1.5 с | «дорогой» кадр без шейдеров |
| **Не «хлыст»** | избегай резких 180° поворотов на записи | они выглядят как баг кадровой частоты |
| **Фикс на действии** | не двигай камеру, когда идёт бой | зритель следит за хитбоксами, а не за камерой |
| **Смена ракурсов** | 2–3 плана на один момент (от первого лица + сбоку + сверху) | тот самый «монтажный» эффект |
| **Высота камеры** | чуть выше глаз (2–3 блока) для общих планов | выглядит кинематографичнее |
| **FOV для «кино»** | 70–80, а не 90–110 | меньше растяжения по краям |
| **HUD** | `F1` — убрать интерфейс на киношных планах | сразу +30% к «дорого выглядит» |

Где это брать: **Flashback** (рендер реплея с любой камеры, 4К/120) — основной инструмент.
**Frameback** — для мгновенных клипов с motion blur.

---

## 2. Свет и время суток

В Minecraft без шейдеров картинка «плоская», и это лечится выбором сцены, а не модами:

- **Golden hour**: рассвет/закат — длинные тени, тёплый свет. Самое выгодное время.
- **Ночь + факелы**: контраст, но следи за бандингом — тут спасает 10 бит.
- **Пещеры**: красиво, но шумно для кодера → больше битрейт при записи.
- **Избегай полудня** в пустыне/на снегу: пересвет, плашки цвета, бандинг.
- **Туман** (`Fog`) на киношных кадрах — можно включать (в отличие от PvP), он даёт глубину.

Не включай «Disable Lighting»/fullbright на красивых кадрах — картинка становится плоской.

---

## 3. Движение и монтаж

| Правило | Числа |
|---|---|
| Средняя длина плана в динамике | 1.5–3 с |
| Длина «красивого» плана | 3–6 с |
| Пауза на «вау»-кадре | 0.5–1 с (не режь сразу) |
| Скорость слоу-мо | 0.4–0.5× из 120 fps (или 0.25× из 240) |
| Склейки на движении | режь в момент удара/прыжка, а не в статике |
| Музыкальный ритм | режь по битам, а не «примерно» |
| J-cut / L-cut по звуку игры | 0.3–0.5 с перекрытия — сглаживает переходы |

Не делай «нарезку ради нарезки»: 20 склеек за 10 секунд = укачивание. Один сильный момент лучше пяти слабых.

---

## 4. Звук: половина воспринимаемого качества

- Игра 100%, микрофон отдельной дорожкой, музыка тише на 6–10 дБ.
- **Музыка не должна перекрывать** удары/шаги: в PvP звук — информация.
- Микрофон: RNNoise (OBS) + компрессор 3:1 + лимитер −1 dB.
- Мастер: **−14 LUFS integrated**, пики ≤ **−1 dBTP** (норма YouTube).
- Резкие «пшыки» (S) лечатся де-эссером в Premiere (`Essential Sound → Dialogue`).

---

## 5. Превью (миниатюра) и первые 3 секунды

- Миниатюра — **отдельный 4К-скриншот** через Fabrishot, не кадр из видео.
- Крупный объект + 3–5 слов текста, читаемых на телефоне (проверь в 320 px).
- Первые 3 секунды: самый сильный момент, без интро и логотипа.
- Название — обещание конкретики («Как я убрал пиксели», «LT1 за 2 недели»), не «Minecraft #12».

---

## 6. Чек-лист «съёмка на сессию»

- [ ] OBS пишет (CQP 16–18), дропов 0
- [ ] Flashback включён для красивых моментов
- [ ] Разминка 10 минут перед игрой (руки, сенса)
- [ ] Записать 30–60 с «общих планов» окружения (пригодится для интро/переходов)
- [ ] Записать 5–10 дуэлей/боёв, из них 1–2 «геройских»
- [ ] Отметить таймкоды интересных моментов (блокнот/OBS marker), чтобы не искать час
- [ ] Скопировать файлы на отдельный диск до монтажа

## 7. Антипаттерны, которые сразу видно

| Антипаттерн | Почему плохо |
|---|---|
| Мышь «дрожит» на каждом кадре | высокий eDPI + низкий fps при записи |
| Камера ходит ходуном | нет View Bobbing 0% и/или реплей не используется |
| Резкие 180° повороты | смазанные кадры, «прыжки» |
| Всё время один ракурс | нет динамики |
| Слишком быстрый монтаж | зритель не успевает понять, что произошло |
| Яркие титры с тенями и обводками | «монтаж 2012»; используй один шрифт, один акцентный цвет |
| Музыка громче игры | теряется PvP-информация и «вес» ударов |
| Заставка 10 секунд | 60% зрителей уходят до начала контента |
