# 11. «Нет сглаживания, полосы вдали, картинка плохая» — что проверить по шагам

Важно понимать: **в сборке нет мода-сглаживания**. Это сделано намеренно — AA делается на уровне
драйвера (DSR/DLDSR), чтобы не конфликтовать с PvP-модами и не терять fps. Если DSR не включён —
Minecraft рендерит без единого сглаживания, и ты видишь ровно то, что видит ваниль: лесенки и «полосы» вдали.

Проверяй строго по порядку — почти всегда проблема в пункте 2 или 3.

---

## 1. Убедись, что моды реально загрузились (10 секунд)

1. В игре нажми `F3`.
2. Смотри правый верхний угол: должно быть `Minecraft 1.21.11` и `Fabric`.
3. В главном меню (Esc) должна быть кнопка **Mods**, в ней ~23 мода, включая `Sodium` и `Sodium Extra`.

Если модов нет — игра запустилась без Fabric-профиля. Открой Prism → инстанс → Edit → Version →
в списке должен быть `Fabric Loader`.

---

## 2. Включи DSR / DLDSR в драйвере (главное!)

### NVIDIA App (новый) или Панель управления NVIDIA

Путь: **NVIDIA App → Graphics → Minecraft** (добавь `javaw.exe`, если его нет) →
или **Панель NVIDIA → Управление параметрами 3D → Программа: javaw.exe**.

| Параметр | Значение |
|---|---|
| **DSR — Factors** | `2.25x` (и/или `1.78x`) |
| **DSR — Smoothness** | `15%` |
| DLDSR (RTX 20+) | `2.25x` — лучше качества при меньшей нагрузке |
| Antialiasing — Mode | `Application-controlled` |
| Antialiasing — FXAA | `Off` |
| Anisotropic filtering | `16x` |
| Power management | `Prefer maximum performance` |
| Vertical sync | `Off` |

Какая DSR-кратность даёт 4К:

| Твой монитор | Нужная кратность | Итоговый рендер |
|---|---|---|
| 1920×1080 | **4.00x** | 3840×2160 |
| 1920×1080 (эконом) | 1.78x | 2560×1440 |
| 2560×1440 | **2.25x** | 3840×2160 |
| 2560×1440 (эконом) | 1.78x | 3413×1920 |

---

## 3. Переключи разрешение (иначе DSR не применится)

DSR создаёт **новые разрешения экрана**. Minecraft берёт разрешение у системы, поэтому:

1. Правый клик по рабочему столу → **Параметры экрана**.
2. **Разрешение экрана** → выбери `3840×2160` (или `3413×1920`).
3. Оставь «Сохранить изменения».
4. Запусти игру, `F3` → строка `Display` должна показывать `3840x2160`.

Если в списке нет 4К — DSR не включился (вернись к пункту 2) или нужен перезапуск игры.

> Курсор и окна Windows станут мелкими — это нормально на время записи. Монитор сам даунскейлит картинку.

---

## 4. Настройки внутри игры (Sodium Extra)

`Options → Video Settings → Quality` (Reese's Sodium Options → вкладка Quality):

| Параметр | Значение | Зачем |
|---|---|---|
| Graphics | **Fancy** | без него часть геометрии рисуется упрощённо |
| Mipmap Levels | **4x** | убирает «муар» и мерцание дальних текстур — те самые полосы |
| Anisotropic Filtering | **16x** | резкость текстур под углом |
| Biome Blend | **5x5** | плавные переходы |
| Clouds | Fancy | на Fast — плоские «фанерки» |
| Leaves | Fancy | иначе листва — плоские квадраты |
| Entity Distance | 100% | |
| Fog | Off (в PvP) / On (кино) | |

И в обычных настройках: **Render Distance 12–16**, **Simulation Distance 8**.

---

## 5. Что считается «нормой» после настройки

| Проверка | Как | Ожидаемо |
|---|---|---|
| Разрешение | `F3` → Display | 3840×2160 |
| Края блоков | Zoomify (зум) на диагональный забор | гладкие, без ступенек |
| Дальние текстуры | посмотри на поле/листву вдали | нет «муара» и ряби |
| Небо | под углом на градиент | нет резких полос (бандинг) |
| fps | `F3` | 100–200 на RTX 4070+ при 4К DSR |

---

## 6. Если всё включено, а сглаживания нет

| Симптом | Причина | Решение |
|---|---|---|
| Разрешение в `F3` осталось 1920×1080 | рабочий стол не переключён | пункт 3 |
| Полосы только вдали, вблизи всё ок | нет мипмапов | Mipmap 4x (пункт 4) |
| Края идеальные, но всё «мыльное» | DSR Smoothness слишком высокий | поставить 15% (не 33–50%) |
| Всё «звенит» и ореолы | включён Sharpening/Image Scaling в драйвере | выключить |
| Картинка как в 480p | запущено окно маленького размера | разверни на весь экран |
| Нет вкладки Quality в Sodium | не установлен Sodium Extra | доустановить мод |
| Ступеньки только на HUD/тексте | это нормально: HUD не проходит через DSR-даунскейл | игнорировать |

---

## 7. Альтернатива: модовое сглаживание (если DSR не заходит)

- Поставь отдельный инстанс: **VulkanMod + Salt's Anti-Aliasing** (MSAA 4x / DLAA / TAA).
- Плюс: настоящее MSAA/TAA внутри игры, без переключения разрешения.
- Минус: несовместим с Sodium-модами и частью PvP-модов, fps ниже.
- Подробно: `03-antialiasing.md`, путь B.
